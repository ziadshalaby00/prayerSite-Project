# PrayerSite

A clean, responsive frontend web application that displays **Islamic prayer times** based on the user's geographical location, along with a daily Quranic verse.

## Features
- Auto-detects user location to fetch accurate prayer times
- Live countdown to the next prayer
- Daily random Quranic verse display
- Responsive card-based UI for all prayer times
- RTL (Right-to-Left) Arabic-ready interface

## Tech Stack
- **HTML5** — Semantic markup
- **CSS3** — Custom gradients, Flexbox, responsive design
- **Vanilla JavaScript** — Core logic, API integration, DOM manipulation
- **Bootstrap 5** — Layout utilities & components
- **Axios** — HTTP client for prayer times API
- **Google Fonts** — Tajawal & Noto Naskh Arabic

## APIs
- Prayer Times API (geolocation-based)
- Quran API (random verse)
